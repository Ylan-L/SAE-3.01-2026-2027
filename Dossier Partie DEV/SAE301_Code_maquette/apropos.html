Le projet

AgriFutur est un projet pédagogique de la SAÉ 3.01, réalisé par un groupe d’étudiants de BUT Informatique à l’IUT de Créteil-Vitry (Université Paris-Est Créteil). Il aide à comprendre comment le climat peut évoluer d’ici 2050 pour quelques cultures.

Les sources

Les projections climatiques (modèles CMIP6) proviennent de Open-Meteo.com, sous licence CC BY 4.0. Les seuils propres à chaque culture sont issus de sources agronomiques, détaillées dans la méthodologie.
