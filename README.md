# SAE-3.01-2026-2027
Voici le README de notre projet, le but du projet est de créer une application web qui transforme des
projections climatiques en informations agro-climatiques compréhensibles et actionnables, à l'échelle
d'une commune.

La question à laquelle nous répondons est : Comment le climat de ma commune
va-t-il évoluer d'ici 2050, et quelles cultures y resteront viables ?
