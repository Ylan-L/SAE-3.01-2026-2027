Pour aller plus loin

Modèles, scénario et seuils.

Modèles utilisés

Projections CMIP6 obtenues via Open-Meteo. Le modèle par défaut est EC-Earth3 ; d’autres peuvent être comparés dans les options avancées.

Scénario

RCP 8.5 : un scénario d’émissions élevées, utilisé comme référence pessimiste.

Calcul des indicateurs

Gel : jours sous le seuil après le débourrement. Chaleur : jours au-dessus du seuil. Eau : pluie moins évaporation. Maturité : chaleur accumulée. Chaque résultat est comparé à la période 1976–2005.
